## Context

The user wants to understand a file quickly without reading through all the code.

## Your task

$ARGUMENTS

1. Read the specified file using the Read tool
2. Analyze its structure and purpose
3. Provide a clear, concise summary including:
   - **Purpose**: What does this file do?
   - **Key Components**: Main classes, functions, or exports
   - **Dependencies**: Notable imports or external dependencies
   - **Usage**: How is this file typically used?

Keep the summary focused and actionable. Highlight any important patterns or notable implementation details.
